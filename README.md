Planned Flutter client for Android and iOS that talks to the same [server](https://github.com/corvin-chess/server) REST and WebSocket protocol as [web](https://github.com/corvin-chess/web), with legal moves via FFI to [chess-core](https://github.com/corvin-chess/chess-core) and design tokens aligned with [design-system](https://github.com/corvin-chess/design-system) and [assets](https://github.com/corvin-chess/assets). No Flutter scaffold, FFI bridge, or play UI is in this repository yet. Everything chess-specific stays Corvin-original; no third-party engines or piece sets.
